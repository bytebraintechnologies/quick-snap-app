# Support

Use [GitHub Issues](https://github.com/bytebraintechnologies/quick-snap-app/issues) for reproducible
bugs and feature requests that can be discussed publicly.

Before opening an issue:

1. Test the latest release.
2. Check existing issues for the same behavior.
3. Include the Quick Snap version, operating system, architecture, installation type, and clear
   reproduction steps.
4. Remove confidential information from captures, recordings, logs, and sample files.

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This repository distributes compiled releases. Application source and implementation pull requests
are not accepted here.
