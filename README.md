# Quick Snap

Quick Snap is a cross-platform screenshot, screen-recording, annotation, pinning, and screen-pen
application.

## Downloads

### Recommended on Windows: Microsoft Store

Use Microsoft Store for the trusted Windows production installation. Microsoft signs the package
and delivers updates automatically.

- [Install Quick Snap from Microsoft Store](https://apps.microsoft.com/detail/9NQKTDS7CBGW)
- Store ID: `9NQKTDS7CBGW`

### Portable previews

The [Releases](https://github.com/bytebraintechnologies/quick-snap-app/releases) page provides
portable preview archives for supported platforms. These builds are **not digitally signed** or
notarized. Windows may show an Unknown publisher warning or block an executable, and macOS may
require additional approval when macOS packages become available.

Every preview has a versioned filename, a matching SHA-256 checksum, and an immutable GitHub
release. Portable previews are intended for users who understand these platform trust limitations.

## Highlights

- Capture a screen, region, window, or scrolling page.
- Annotate with shapes, arrows, text, callouts, symbols, stamps, blur, pixelation, and redaction.
- Record the screen with audio and export clips.
- Pin captures as borderless reference windows.
- Draw over the live or frozen desktop with the screen pen.
- Export PNG, JPEG, WebP, PDF, and clipboard-ready images.

See the complete [Quick Snap feature catalog](FEATURES.md), including capture modes, editor tools,
screen pen, recording, export formats, shortcuts, and platform support.

## Installing a portable preview

1. Open the latest release.
2. Download the archive for the required platform and its adjacent `.sha256` file.
3. Verify the archive's SHA-256 value before extracting it.
4. Run the preview only if you accept the operating system's unsigned-application warning.

This repository intentionally contains no application source code. It is the official distribution,
release-notes, and support repository for the proprietary Quick Snap application.
